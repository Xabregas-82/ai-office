
# PRD: Aplikasi Catatan Sederhana

## Tujuan

Web app untuk mencatat ide dengan cepat.

## Fitur

1. Pengguna bisa mendaftar dan login dengan email.
2. Pengguna bisa membuat, mengedit, dan menghapus catatan.
3. Catatan bisa diberi label warna.
4. Ada kolom pencarian catatan.

## Catatan teknis

- Website responsif (bisa dibuka di HP).
- Data disimpan di database.
